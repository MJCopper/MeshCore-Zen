    Named destination trace acknowledgement validation

    Date: 2026-10-25. Current working tree on meshcore/sensor, based on adc6cab4 (trace), which includes the existing recovery, acknowledgement and fixed 60-second cap changes. No commit, flash or physical radio acceptance is implied.

    Implemented behaviour

    A uniquely known 7188 named Hilltop Repeater produces:

    BME680 Sensor: Trace requested to Hilltop Repeater, please wait up to 60 seconds.

    The same cache lookup returns the full identity and copied destination label. Full display words and case are preserved; the separate compact hop formatter still removes Repeater as before. ASCII controls/whitespace are normalized, valid UTF-8 is preserved, and a known identity with no usable name uses lowercase 7188. Unknown and ambiguous prefixes retain their errors and clear lookup outputs. Adverts without a name field retain existing cache admission behaviour. No cache schema, authentication or ACL changes were made.

    The acknowledgement formatter snapshots sensor prefix and destination before queueing. A rename or cache eviction cannot change queued/retried text or the full key used for discovery. It fits one 160-byte public message, truncating only the destination at a valid UTF-8 boundary when necessary. If no meaningful label fits, the prefix fallback is tried; if that cannot fit either, formatting fails before acceptance. Fixed text and the timeout suffix cannot be truncated.

    Bare acknowledgement, final trace formatting, node ordering, averaged SNR, channels/scopes, command controls and the 55/60-second cutoffs are preserved. The earlier sensor-versus-Zen discovery failure remains a separate investigation.

    Test evidence

    New tests cover:

    • Full display name with Repeater, normalized whitespace/control characters, unnamed/invalid UTF-8 fallback, maximum stored UTF-8 names and cache replacement.
    • Clearing full-key and label outputs on unknown or ambiguous resolution; unchanged compact hop labels and existing cache persistence behaviour.
    • Exact 160-byte acknowledgement, one-byte overflow, UTF-8-safe truncation, fallback when no valid destination character fits, and impossible prefixes.
    • Frozen mutable input across definitely-unsent and uncertain failures.
    • Real Dispatcher named acknowledgement before discovery, uppercase prefix, same-name/different-key identities, and decryption with the selected full key. Decryption with the other identity fails, ensuring names do not select keys.
    • Queue rejection followed by cache/sensor rename, and eviction of the selected cache entry before retry; emitted text and discovery identity remain frozen.
    • Scoped real-network delivery with exact named acknowledgement on both channels and both path-hash widths, alongside unchanged final results.

    Existing acknowledgement ownership/recovery, unknown/ambiguous rejection, rate-limit/control, timing, fallback, SNR, scope and packet-pool regressions also run. Legacy exact-phase tests explicitly isolate acknowledgement through their transport seam; dedicated acknowledgement tests and network tests use the real Dispatcher. The seam's message recognition now includes both acknowledgement forms.
