# Quick Replies

[Back to README](https://github.com/MJCopper/MeshCore-Zen/blob/zen/main/README.md)

Hold Enter in a conversation to open Quick Replies. Zen provides ten built-in
positive, neutral and negative responses plus five editable custom replies.

Edit custom entries under **Settings › Quick Replies**. Empty entries do not
appear in the picker. They support the same time, location and active-sensor
placeholders as message composition. Selecting a reply inserts it into the
editor so it can be reviewed or changed before sending.
