# Repeater Mode

[Back to README](https://github.com/MJCopper/MeshCore-Zen/blob/zen/main/README.md)

Open **Tools › Repeater Mode** to let the companion forward MeshCore traffic in
the background. It uses the current **Settings › Radio** configuration. Press
Enter or Left/Right to toggle it; operation continues after the screen closes.

| Parameter | Value |
| --------- | ----- |
| RX delay | 10 |
| Flood TX airtime factor | 0.5 |
| Direct TX airtime factor | 0.3 |
| Yield | ×2 |
| Duplicate suppression | On |

Remote repeater configuration is handled through
[Node Administration](../node_admin/node_admin.md).
