# Repeater Mode

[Back to README](../../../README.md)

Open **Tools › Repeater Mode** to forward mesh traffic in the background.
Press Enter or Left/Right to turn it on or off. It uses your current
**Settings › Radio** configuration and continues after leaving the screen.

Forwarding timing and duplicate suppression are handled automatically.
To change a remote repeater's settings, use
[Node Administration](../node_admin/node_admin.md).
