# Favourites Dial

[Back to README](https://github.com/MJCopper/MeshCore-Zen/blob/zen/main/README.md)

The Favourites home page is a four-slot speed dial in one column. Each pinned
entry shows its unread DM count. Pinning is independent of MeshCore's Favourite
star, which controls filtering, Child Mode access and list ordering.

- **Enter** on a contact opens its transcript.
- **Enter** on `+` opens the contact picker.
- **Hold Enter** offers Add, Change or Remove.
- A DM context menu can pin, move or unpin its contact.

The picker lists starred contacts first, recent DM contacts next, then other
chat contacts. Moving an existing pin does not duplicate it. A deleted contact
frees its slot automatically.

The page can be reordered under **Settings › Home Pages**. Child Mode can hide
the page and blocks all editing while locked.
