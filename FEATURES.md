# Zen features

Zen extends MeshCore companion firmware with standalone controls for the
Wio Tracker L1. See [Getting Started](docs/getting_started.md) for navigation.

| Feature | What you can do |
| ------- | --------------- |
| Messages | Send direct, channel and room messages; read conversations, track delivery and resend failures |
| Text entry | Use predictive T9, ABC or CardKB, plus word suggestions, Quick Replies and emoji |
| Favourites | Star contacts, rooms and channels, and keep four contact shortcuts on the home page |
| Clock | Open the latest unread conversation, choose 12/24-hour time and set city or fixed-UTC time zones |
| GPS | Choose power-saving position checks, see fix age and follow direction of travel |
| Sensors | Request and view readings from saved sensor nodes |
| Radio | Choose built-in or custom presets, adjust radio settings and control advert location sharing |
| Notifications | Choose sounds, screen wake, per-contact alerts, Quiet Time and temporary DND |
| Child Mode | Restrict access with a parent PIN and permitted favourites |
| Node List | Discover, inspect, ping and manage repeaters, room servers and sensors |
| Repeater Trace | See round-trip time and each link's SNR in both directions |
| Node administration | Log in to remote nodes, inspect settings and confirm changes |
| Repeater Mode | Forward mesh traffic in the background |
| Battery | Check charge status and estimated runtime; use emergency communications during Low Power |
| Signal indicator | Read four-bar reception quality and inspect recent samples |
| Virtual pet | Feed, train and evolve a pet, with five games and daily mesh rewards |
| Diagnostics | Check device status, storage, signal and recent errors |

Open [Settings](docs/zen_features/settings_screen/settings_screen.md) to customise
home pages, display, keyboard and other preferences. Detailed guides are linked
from [README.md](README.md).
